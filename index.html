⚙ Geoapify connection · free trial

Use your Geoapify Places API key to find real nearby restaurants. No Google Cloud billing required. Restaurant ratings and cuisine labels may be unavailable; FoodWise won't invent them.

Restrict your key to this website in the Geoapify dashboard where supported. The key stays in your browser storage, but browser API keys are not secret from someone using the website. Location is requested only for searches.

⚙ Google Places connection · optional

Demo mode needs no key. For live results, enable Maps JavaScript API and Places API (New) in Google Cloud, enable billing and restrict a browser API key to this HTTPS website. Google usage charges may apply. Do not paste an unrestricted key.

FoodWise requests location only when making a live recommendation. Favourites and family/friends preference are saved on this phone, not uploaded to FoodWise.

Private-use prototype on a publicly accessible page. No ordering, booking or promotion verification. Not affiliated with Google.
